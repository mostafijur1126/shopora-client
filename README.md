## 📖 About Shopora

**Shopora (শপোরা)** is a web-based shopping project published online to provide visitors with a dedicated digital storefront. Its goal is to present a clear, convenient, and modern online-shopping experience.

**Live Website:** [https://shopora-live.vercel.app/](https://shopora-live.vercel.app/)

> The live website is the best place to review the currently available interface and functionality. Detailed implementation information should be maintained alongside the project's source code.

## ✨ Project Highlights

- **Online storefront** — a web destination for the Shopora shopping experience.
- **Customer accounts and guest checkout** — customers can sign up or log in, while guests can order without an account.
- **Guest data migration** — guest contact details, cart variants, and local order history persist in the browser; verified guest orders and carts are associated with an account after successful sign-in.
- **Customer administration** — the protected admin Customers tab reads registered customers and guest purchasers from the database, including order totals and history.
- **Modern presentation** — a clean, customer-focused digital presence.
- **Live deployment** — publicly accessible through Vercel.
- **Project-specific ownership** — licensing is restricted to the single authorized license holder named below.

_The features above describe the source implementation; deployment availability depends on the configured backend and database._

### Run locally

The public deployment URL alone does not identify the exact framework, package manager, environment variables, or startup command. To run the application locally:

Prerequisites

- Node.js 20+
- Git
- Clone the repository
- npm install
- cp .env.example .env.local
- npm run dev
- Open http://localhost:3000 to view the application.
- Backend Setup
- npm run dev
- Start the backend server.

Production Build

- npm run build
- npm run preview
